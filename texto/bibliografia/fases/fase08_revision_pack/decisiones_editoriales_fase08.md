# Decisiones editoriales - Fase 8

1. El artículo no se presenta como una publicación de software. La contribución se reformuló como un experimento hidrológico de ablation sobre hibridación física--ML estocástica.

2. PISCOp v3.0 se reporta como fuente de precipitación usada en el estudio, pero se evita atribuirle una publicación que no corresponde. La referencia Aybar et al. (2020) se usa solo para documentar la familia PISCO/PISCOp y la construcción publicada de PISCOp v2.1.

3. PISCOt v1.2 se documenta con Huerta et al. (2023), porque esta versión sí cuenta con publicación científica específica.

4. La estimación de PET se incorporó formalmente mediante Hargreaves--Samani, por ser consistente con el uso de temperatura mínima y máxima como insumos disponibles.

5. El nuevo mapa del área de estudio se trata como una figura hidrológica, no como una salida de una API o herramienta. El caption enfatiza el soporte espacial de los forzantes y la unidad de simulación.

6. Se mantuvo la auditoría de backend y leakage porque no describe el software desarrollado como producto, sino las condiciones bajo las cuales se generaron los resultados del manuscrito.
